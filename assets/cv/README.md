# assets/cv/

Put your CV PDF in this folder, named exactly:

    cv.pdf

The download buttons on the CV and Contact pages already point at
`assets/cv/cv.pdf`, so once the file is here everything works with no code
changes.

Notes:
- Keep the file under ~2 MB so it downloads quickly on mobile.
- If you would rather use a different filename, update the href in
  `cv.html` and `contact.html` (search for `cv.pdf`).
- A one-page placeholder PDF is included so the download button works
  immediately. Overwrite it with your real CV.
- Do not commit sensitive personal information (e.g. a full home address or
  ID numbers) to a public repository.
